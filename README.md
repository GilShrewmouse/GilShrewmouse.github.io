# Ekaterina Podsevalova – personal site

Portfolio of a game QA / LQA specialist: 40+ titles, from Cyberpunk 2077 to Hades II.

🔗 **Live site:** https://gilshrewmouse.github.io/

## About
Built with Claude Code and Jekyll, hosted on GitHub Pages; mostly HTML and CSS.

- The game list lives in `_data/games.yml`, and contact buttons are in `_data/links.yml`
- All styling is in `assets/css/style.css`

## Run locally
Needs Ruby 3.3.

    bundle install
    bundle exec jekyll serve

Then open http://localhost:4000
